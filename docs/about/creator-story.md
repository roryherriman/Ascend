# Creator Story

Ascend was built by one person.

The creator is a technology professional with a background in systems, infrastructure, cloud technologies, automation, and enterprise IT. That background is not traditional software development — the approach to building Ascend reflects someone who knows how systems fit together and how to get things done technically, but is not a career software engineer by training.

The creator is also a competitive World of Warcraft player and raider. Ascend came from that experience directly: the frustration of not having clear, honest performance data during progression — only parse colors and vague impressions. Ascend is the tool the creator wanted to use and couldn't find.

## How it was built

Ascend was built with significant use of modern AI tools, particularly in code generation and iteration. The creator is not an experienced WoW addon developer, and acknowledges that without AI assistance the scope of this project would have been substantially narrower.

That assistance does not reduce the creator's responsibility for the product. Every architectural decision, feature, behavior, and release is human-directed. The creator reviews, understands, and stands behind the code in this repository.

See [ai-assisted-development.md](ai-assisted-development.md) for the full disclosure on how AI tools were used.

## What this means for users

- Ascend is a one-person project, not a company or team
- There is no commercial backing, venture funding, or monetization model
- Updates and maintenance depend on one person's time
- The creator is reachable through the GitHub repository

## What is not disclosed here

This document discloses what is relevant to understanding who built this and how. It intentionally does not include personal identifying information that serves no legitimate user need: employment history, personal guild or character names, personal progression history, education, location, age, or other personal details. That boundary is deliberate and permanent.
